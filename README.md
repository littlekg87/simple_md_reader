<summary><h2>🇰🇷 한국어</h2></summary>

설치 없이 HTML 파일 하나로 동작하는 md(마크다운) 리더입니다.

- **버전**: 1.0.0 (2026년 10월)
- **만든 사람**: 김근하 — 대한민국, 국립부경대학교 해양인문학연구소 전임연구원
- **포트폴리오**: [github.com/littlekg87/littlekg87](https://github.com/littlekg87/littlekg87)
- **제작 방식**: Claude(Anthropic)와 함께 바이브 코딩으로 만들었습니다.
- **라이선스**: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.ko) (저작자표시-비영리 4.0 국제)
- **상업적 이용 문의**: littlekg87@gmail.com

### 바로 쓰기

**https://littlekg87.github.io/simple_md_reader/**

Chrome이나 Edge로 위 주소를 열면 설치 없이 바로 쓸 수 있습니다. 여는 md 파일은 내 컴퓨터 안에서만 읽고 저장하며, 어디로도 올라가지 않습니다.

### 내려받아 쓰기

**[⬇️ simple_md_reader.html 내려받기](https://github.com/littlekg87/simple_md_reader/releases/latest/download/simple_md_reader.html)** (항상 최신 버전)

프로그램은 HTML 파일 하나가 전부입니다. 받은 `simple_md_reader.html`을 **Chrome** 또는 **Edge**로 열면 됩니다. 파일을 브라우저 창에 끌어다 놓아도 됩니다.

### 버전과 업데이트

- 지금 쓰는 버전은 프로그램 시작 화면의 제목 옆과 정보(ⓘ) 창에 나옵니다.
- 버전마다 바뀐 내용은 [CHANGELOG.md](CHANGELOG.md)에, 지난 버전 파일은 [Releases](https://github.com/littlekg87/simple_md_reader/releases)에 있습니다.
- 새 버전이 나오면 위 링크로 다시 받아 기존 파일을 바꾸면 됩니다. 최근 파일 목록과 보기 설정은 그대로 남습니다.

### 사용 방법

1. 위 주소로 들어가거나, 내려받은 `simple_md_reader.html`을 **Chrome** 또는 **Edge**로 엽니다.
2. **파일 열기**로 md 파일을 고릅니다. 문서 속 이미지나 다른 md 파일로 가는 링크까지 쓰려면 **폴더 열기**로 그 파일이 든 폴더를 엽니다.
3. 본문을 더블클릭하거나 `Ctrl+E`를 누르면 편집 화면이 열리고, `Ctrl+S`로 원본 파일에 저장합니다.

글꼴과 수식·다이어그램 기능을 불러오기 위해 인터넷 연결이 필요합니다.

### 주요 기능

- 라이트 / 다크 / 내 색(배경색·글자색 직접 선택) 테마
- 글꼴: 기본 3종 또는 내 컴퓨터에 설치된 글꼴 중 직접 선택
- 글자 크기·줄 간격·본문 폭 조절, 화면 배율(메뉴·버튼 크기, 큰 화면에서 자동 확대)
- 읽기 ↔ 원문 편집 전환, 편집하며 오른쪽에 나란히 미리보기, 원본 파일에 바로 저장, 수정 취소
- 새 메모: 빈 화면에 바로 쓰고 저장할 때 위치·이름 정하기, 저장 전 메모는 브라우저에 임시 보관
- 최근 연 파일 목록, 폴더 목록
- 목차, 표, 각주(마우스를 올리면 미리 보기), 수식(KaTeX), Mermaid 다이어그램, 코드 색 강조
- 다른 프로그램이 파일을 고치면 화면에 자동 반영
- 한국어 / English 화면 전환

### 단축키

| 키 | 기능 |
|---|---|
| `Ctrl+E` | 편집 ↔ 읽기 |
| 더블클릭 | 그 자리에서 바로 편집 |
| `Ctrl+S` | 원본 파일에 저장 |
| `Esc` | 편집 끝내고 읽기로 |
| `Ctrl+휠`, `Ctrl+=` / `Ctrl+-` | 글자 크기 |
| `Alt+P` | 편집하며 미리보기 켜기/끄기 |
| `Alt+N` | 새 메모 |
| `Ctrl+O` / `Ctrl+Shift+O` | 파일 열기 / 폴더 열기 |
| `Ctrl+\` | 파일 목록 접기 |

### Try it now

**https://littlekg87.github.io/simple_md_reader/**

Open the link in Chrome or Edge and start right away. Files you open are read and saved only on your own computer; nothing is uploaded.

### Download

**[⬇️ Download simple_md_reader.html](https://github.com/littlekg87/simple_md_reader/releases/latest/download/simple_md_reader.html)** (always the latest version)

The whole program is a single HTML file. Open the downloaded `simple_md_reader.html` in **Chrome** or **Edge**, or drag it onto a browser window.

### Versions and updates

- The version you are using is shown next to the title on the start screen and in the About (ⓘ) window.
- See [CHANGELOG.md](CHANGELOG.md) for what changed in each version, and [Releases](https://github.com/littlekg87/simple_md_reader/releases) for earlier files.
- When a new version comes out, download it again from the link above and replace your old file. Your recent files and view settings are kept.

### How to use

1. Open the link above, or open the downloaded `simple_md_reader.html` in **Chrome** or **Edge**.
2. Click **Open file** to pick a Markdown file. To use images and links to other .md files, click **Open folder** and choose the folder that contains it.
3. Double-click the text or press `Ctrl+E` to edit, and press `Ctrl+S` to save to the original file.

An internet connection is needed to load fonts, math and diagram support.

### Features

- Light / Dark / My colors (pick any background and text color) themes
- Fonts: three built-in choices, or any font installed on your computer
- Adjustable text size, line spacing and text width, plus interface size (auto-enlarged on large screens)
- Switch between reading and editing, a side-by-side preview while editing, save straight to the original file, revert changes
- New notes: start writing right away and choose a name and location when you save; unsaved notes are kept in your browser
- Recent files list and folder list
- Table of contents, tables, footnotes (hover to preview), math (KaTeX), Mermaid diagrams, code highlighting
- Updates the page automatically when another program changes the file
- Korean / English interface

| `Alt+P` | Show/hide preview while editing |
| `Alt+N` | New note |
| `Ctrl+O` / `Ctrl+Shift+O` | Open file / Open folder |
| `Ctrl+\` | Toggle file list |
